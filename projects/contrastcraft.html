01 / Overview

FIXING ACCESSIBILITY WITHOUT DESTROYING BRAND COLOR IDENTITY.

Low-contrast text affects 81% of websites, yet naive fixers force everything to black or white. ContrastCraft resolves CSS variables accurately and adjusts HSL lightness while preserving brand hue.

01

Exact W3C & APCA Math

Linearizes sRGB channels for exact W3C contrast ratios alongside perceptual APCA Lc readability scores.

02

Cascade & Alpha Compositor

Parses HEX (3/4/6/8), RGB/RGBA, HSL/HSLA, 148 named colors, and CSS var(--tokens) with Porter-Duff alpha compositing.

03

N x N Token Compatibility Matrix

Evaluates every foreground x background design token pair and simulates cascade ripple impact before editing CSS.

04

Hue-Preserving HSL Fix Studio

Finds the minimal lightness delta needed to pass AA (4.5:1) or AAA (7.0:1) without shifting brand hues.

05

Safe Reversible Diff Patcher

Previews side-by-side split diffs and applies CSS edits with automatic .bak snapshots and 1-click revert.

06

7 Structural HTML A11y Checks

Audits missing alt text, unlabeled inputs, skipped heading hierarchy, ARIA role errors, and empty buttons/links.
