01 / Overview

ELIMINATING THE 80% MANUAL DATA CLEANING BOTTLENECK.

Silent duplicates, trailing whitespace, numeric strings, and corrupted delimiters break downstream ML models. The inspector diagnoses every flaw automatically with copyable code fixes.

01

Encoding & Delimiter Sniffer

Detects UTF-8, Latin-1, and CP1252 encodings plus comma, semicolon, tab, and pipe separators automatically.

02

5-Pillar 0–100 Score (A–F)

Weights Completeness (25%), Uniqueness (20%), Validity (20%), Outlier Health (15%), and Structural Integrity (20%).

03

Dual Outlier Detection

Runs Tukey's Interquartile Range (IQR) bounds alongside standardized |z| > 3.0 anomaly checks per numeric feature.

04

Semantic Hygiene Audit

Detects untrimmed whitespace, numbers stored as strings, negative values, all-null rows, and constant columns.

05

Python Remediation Snippets

Emits actionable, copy-pasteable Pandas cleaning code tailored to each detected anomaly or missing column.

06

Multi-Format Audit Deliverables

Exports standalone interactive HTML reports, CI/CD JSON schemas, Markdown summaries, and one-click auto-cleaned CSVs.

04 / Technical Details

5 PILLARS OF DETERMINISTIC DATA QUALITY.

Key modules, rules, safety checks, and automated test results documented in the repository.

Quality Pillar Weight Penalization Criteria
Completeness 25% Overall missing cell %, all-null rows, 100% empty columns
Uniqueness 20% Exact duplicate rows & candidate primary-key collisions
Validity & Consistency 20% Untrimmed whitespace, stringified numbers, negative anomalies
Structural Integrity + Outliers 20% + 15% = 35% Schema shifts, constant cols, Tukey IQR & |z| > 3.0 counts
