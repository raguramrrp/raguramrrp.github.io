01 / Overview

ORGANIZING INBOX ATTACHMENTS WITHOUT MANUAL SORTING.

Invoices, contracts, and tax receipts arrive scattered across email threads with cryptic filenames. ATTACHORA monitors mail queues, inspects true binary magic bytes, categorizes documents, and archives them into standardized folder hierarchies.

01

Attachment Queue Stream

Live table tracking received files with true MIME detection, sender context, and automated confidence chips.

02

Smart Filing Rules

Configurable pattern-matching rules sorting attachments into categorized directories based on sender, file extension, and naming tokens.

03

Organized Library Explorer

Interactive file tree workstation displaying stored documents with one-click preview and full-text metadata search.

04

Integrity & Security Center

SHA-256 hash digests prevent duplicate file storage and ensure tamper-evident storage compliance.

05

Automated Renaming

Transforms obscure attachment filenames (e.g., Scan_001.pdf) into standardized canonical paths based on metadata.

06

Local-First Storage

Runs 100% locally on your machine without transmitting sensitive corporate documents to third-party cloud servers.

02 / Architecture

HOW IT WORKS.

Deterministic MIME parsing and regex categorization pipeline backed by FastAPI and React 19.

STAGE 01

MIME Ingestion

Parses raw email streams and extracts binary attachments.

→
STAGE 02

Magic Bytes Audit

Verifies true file types (PDF, XLSX, CSV) to block spoofing.

→
STAGE 03

Rule Evaluation

Matches sender domain and subject regex against filing rules.

→
STAGE 04

SHA-256 Check

Suppresses duplicate files via content-addressable hashing.

→
STAGE 05

Vault Archival

Writes sanitized, renamed files to structured target library.
