01 / Overview

RECLAIM DISK SPACE WITHOUT DESTRUCTIVE BLACK-BOX DELETION.

Naive cleaners freeze RAM on multi-GB files or permanently erase last surviving copies. FileGuard streams chunked hashes, guards protected system folders, and keeps at least one master copy locked.

01

3-Stage Pruning Funnel

Stage 1 exact size clustering -> Stage 2 4KB fast pre-hash -> Stage 3 streaming 64KB SHA-256 content digests.

02

64-Bit dHash Photo Similarity

Detects resized, re-saved, or cropped near-duplicate photos via grayscale difference hashes and Hamming distance.

03

Retained-Copy Safety Block

Explainable Selection Advisor marks oldest/shallowest/cleanest master copy and physically blocks deleting 100% of a cluster.

04

Reversible UUID Quarantine

Moves redundant copies into an isolated UUID vault with manifest metadata; press Ctrl+Z for 1-click conflict-safe restoration.

05

Protected OS Path Guards

Blocks destructive scans or quarantines inside C:\Windows, Program Files, and core system hierarchies.

06

Non-Double-Counting Analyzer

Accurate directory tree size attribution avoiding nested child-folder double-counting while logging storage trends in SQLite WAL.
