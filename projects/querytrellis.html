01 / Overview

BRIDGING PLAIN ENGLISH AND HIGH-PERFORMANCE SQL.

Writing and tuning complex relational queries requires navigating syntax errors, indexing bottlenecks, and subtle dialect differences. QueryTrellis Studio unifies natural language synthesis, Monaco IDE editing, automated AST bug fixing, and execution plan benchmarks.

01

Schema-Grounded Query Studio

Translates natural language prompts against active database schemas, asks structured clarification questions for ambiguities, and blocks nonexistent table hallucinations.

02

Multi-Dialect Monaco SQL IDE

Offline-bundled Monaco editor supporting PostgreSQL, MySQL, SQLite, and SQL Server with AST syntax validation, schema tree explorer, and CSV/JSON export.

03

Automated SQL Debugger

Diagnoses missing tables, ambiguous columns, missing JOIN predicates, three-valued NULL bugs, and datatype mismatches, generating interactive Monaco diff patches.

04

Three-Tier Query Optimizer

Enforces static AST suggestions + index DDL recommendations, non-executing estimated EXPLAIN plans, and opt-in measured EXPLAIN ANALYZE execution timing.

05

Visual SQL Academy (21 Lessons)

Interactive curriculum across Beginner to Advanced tiers featuring DuckDB step-by-step execution traces, progressive hints, and a custom query tracer.

06

Database Sandbox & Safety Guardrails

Uploads .sql, .csv, and .json files into isolated DuckDB sandboxes, connects live external databases, and enforces strict read-only / HMAC-confirmed write policies.
