01 / Overview

ZERO-DATA-LOSS FILESYSTEM AUTOMATION FOR WINDOWS.

Cluttered Downloads folders mix receipts, datasets, installers, and duplicate archives. SortIQ previews every planned file move upfront and logs reversible batches in SQLite WAL.

01

Dual GUI + Headless CLI

Operates as an interactive Obsidian/Electric Violet Tkinter app (PyInstaller .exe ready) or headless CLI for Task Scheduler scripts.

02

Priority Wildcard & Regex Rules

Evaluates custom rules like *invoice* or regex:^Screenshot_\d+ alongside file size and modification age bounds.

03

Two-Tier SHA-256 Dedup

Clusters by exact byte size in O(N) time (skipping 90%+ unique files) before streaming 64KB chunked SHA-256 hashes.

04

Dry-Run Plan Simulator

Displays exact proposed source -> target routes, matched rules, collision tags, and duplicate flags without touching disk.

05

Temporal Year-Month Clustering

Organizes archives chronologically by Year (2026/), Year-Month (2026-10/), or Full Date hierarchies.

06

1-Click SQLite Rollback

Every move is recorded under a transaction Batch ID in WAL SQLite, restoring moved files cleanly in one click or CLI command.
